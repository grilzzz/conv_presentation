# Иллюстрации

`operator_demo_mnist.png` создаётся скриптом `scripts/make_operator_demo.py`.
На всех панелях используется один и тот же образ MNIST и пространственное ядро
3×3, у которого каждый коэффициент равен `1/9`. Для deformable-версии смещения
заданы вручную только ради объяснения механики; они не являются offsets из
обученного CIFAR-10 эксперимента.
